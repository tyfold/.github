# Tyfold

**Your agents work in a terminal. Tyfold is an IDE that starts there.**

Tyfold is a desktop IDE with the terminal in the middle. Your agents, your
build and your ssh logins run there, and files, diffs and search are reached
from it. It is for developers whose code is mostly written by Claude Code,
Codex or opencode, and who spend the day directing those agents and checking
what comes back.

## What it has

- Many sessions, with their status, in layouts and groups of your own.
- A file browser and editor. Click a file path in any terminal and it opens at
  the line.
- A prompt queue for agents.
- Git built in.
- A CLI and MCP that let agents open their own Tyfold sessions, with your
  approval.
- A diagram pane that agents can draw in.

Tyfold doesn't host a model or hold your provider keys. Your own CLI signs in,
exactly as it does now.
